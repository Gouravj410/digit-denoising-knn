# 🧹 Digit Image Denoising using KNN – MNIST Project

This project uses the MNIST dataset to denoise noisy handwritten digit images using a KNN model.

## 🔧 How it works
- Trains a KNN model using noisy vs. clean images
- Builds a Streamlit app to upload and denoise images
- Predicts and shows the cleaned version in real-time

## 🚀 How to Run
1. Clone the repo or download files
2. Install dependencies:
pip install -r requirements.txt
3. Run the app:
streamlit run denoise_app.py

## 📁 Files
- `sample.py` – Train and save the model
- `denoise_app.py` – Streamlit UI to test the model
- `knn_cleaner_model.joblib` – Trained model file
